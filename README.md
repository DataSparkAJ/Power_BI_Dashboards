# Data Jobs Dashboard w/ Power BI

## Introduction

This dashboard was created for **Job Seekers, Job Transitioners, and Job Swappers** to help make sense of the 2024 data job market.

Information about data roles, salaries, and locations is often scattered across platforms. Using a **real-world dataset of 2024 data job postings**, this project consolidates job demand, compensation trends, and work characteristics into a **single, interactive Power BI dashboard** for easy exploration.

---

## Dataset Overview

The dataset includes job postings from 2024 related to data roles, with attributes such as:

- Job Title
- Job Count
- Median Yearly Salary
- Median Hourly Salary
- Job Location (Global)
- Work From Home (WFH) Indicator
- Degree Requirement Indicator
- Health Insurance Availability
- Hiring Platform
- Employment Type

---

## Dashboard Overview

### Page 1: High-Level Market View

![Dashboard Page 1](/POWER_BI_DASHBOARDS/Images/Project1_Page1.png)

This page serves as the mission control for the data job market. It highlights key KPIs such as total job count, salary star rating, median yearly salary, and median hourly salary to provide a quick understanding of overall market conditions.

Key insights include job posting trends over time, comparisons between yearly and hourly compensation across roles, demand by job title, and a detailed table showing job counts and salary metrics.

---

### Page 2: Job Title Drill Through

![Dashboard Page 2](/POWER_BI_DASHBOARDS/Images/Project1_Page2.png)

This page provides a detailed, role-specific deep dive. From the main dashboard, users can drill through to analyze a single job title and explore salary ranges, work-from-home availability, degree requirement mentions, and benefits.

It also includes a global map of job locations, an analysis of hiring platforms, employment type distribution, and navigation controls to return to the main dashboard.

---

## Skills Showcased

- **Data Transformation (ETL) with Power Query**  
  Cleaned and prepared raw job posting data by handling missing values, adjusting data types, and creating calculated columns.

- **DAX Measures & KPIs**  
  Developed measures for job count, median yearly salary, median hourly salary, salary ratings, and percentage-based indicators.

- **Data Visualization**  
  Created bar charts, line and area charts, scatter plots, tables, treemaps, donut charts, map visuals, and KPI cards.

- **Geospatial Analysis**  
  Visualized the global distribution of data jobs using map visuals.

- **Interactive Reporting**  
  Implemented slicers, drill-through functionality, cross-filtering, and navigation buttons for a seamless user experience.

- **Dashboard Design & Data Storytelling**  
  Designed a clean and intuitive layout that guides users from high-level market insights to detailed role-level analysis.

---

## Key Insights

- Data Engineer and senior-level roles show higher median salaries compared to analyst roles.
- Job postings peaked mid-year before declining toward the end of 2024.
- North America and Europe contain the highest concentration of data job postings.
- Most data roles are full-time, with a smaller proportion offering remote work.
- Degree requirements are not mentioned in a significant portion of job postings, depending on role.

## How to Use

1. Use the **Job Title slicer** to filter roles.
2. Review KPI cards for quick market insights.
3. Select visuals to cross-filter the dashboard.
4. Use **Drill Through** to explore role-specific details.
5. Navigate back to the main page using buttons.

---

## Conclusion

This dashboard demonstrates how **Power BI** can transform raw job posting data into a powerful tool for career and market analysis. By enabling users to slice, filter, and drill through data, the report helps uncover trends, compare roles, and make informed decisions about career paths using real-world 2024 job market data.
